# À corriger

- Réglages de l'orme encore approximatifs (vérifiés seulement sur un portage Python de la simulation) : à ajuster après les essais sur téléphone.
- Après une taille sévère, la repousse est lente : la vigueur ne dépend que de la lumière. Les réserves des racines viendront avec l'étape racines.
- Pas de feuilles : les pousses de l'année sont en vert.
