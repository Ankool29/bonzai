# Étape 2 — les feuilles de l'orme (validé)

- Une feuille par nœud, seulement sur les pousses de l'année (le vieux bois n'en a pas).
- Petite feuille ovale (~2 cm), inclinée vers le haut ; pas encore de pixel art.
- Cycle caduc : débourrement avec la pousse, vert l'été, jaune en octobre, chute en novembre, nu l'hiver.
- Branche affaiblie : feuilles jaunies et clairsemées.
- Bouton « Feuilles » pour masquer le feuillage. Toucher le feuillage sélectionne la branche.
- Feuilles purement visuelles : l'ombre reste calculée sur les bourgeons (même position).
