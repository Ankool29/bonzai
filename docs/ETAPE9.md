# Étape 9 — caméra libre pour tailler (validé)

- Un doigt : rotation autour du point visé, de dessous à dessus (inclinaison ±86°).
- Deux doigts : pincer pour zoomer (jusqu'à 3 cm), glisser pour déplacer le point visé dans le plan de l'écran.
- Double-tap sur une branche : la caméra glisse en douceur vers ce point et s'en rapproche.
- Bouton « Recentrer » : vue d'ensemble de l'arbre. La vue ne se recentre plus toute seule.
- Simple tap : sélection, inchangée.

Détails du bois : jeunes rameaux plus fins (1,2 mm de diamètre au lieu de 2,4), contour proportionnel sur les
rameaux fins, anneaux plus irréguliers (trois ondulations autour du bois et renflements le long du bois).
